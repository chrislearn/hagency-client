# Desktop Room 信息面板设计与验收

聊天标题栏只保留 Room 名称及右侧信息面板开关，移除重复的 Invite my Agent。开关使用右侧分栏图标，展开时以选中底色与填充右栏表示状态；再次点击关闭。宽窗口与聊天并列，窄窗口保留浮层以及 Esc/外部点击关闭规则，不能挤掉输入框。

右侧固定摘要显示房间名称和成员数量。搜索历史与共享附件使用紧凑图标按钮，继续打开原有历史/媒体页面。摘要后提供 Overview / Members 标签：

- Overview：Room ID、房间主题、通知设置、Agent Access 和原有审批入口。
- Members：成员头像、名称及截断的 Matrix ID；邀请成员、邀请自己的 Agent、Agent 选择和原请求恢复入口在此归组。

成员列表与概览操作不再共用基于成员数量的硬编码偏移，使用明确行类型映射绘制与点击，避免搜索/成员/通知点击进入错误操作。标签切换只切换呈现，不清理原邀请的幂等请求；切换 Room、服务器或账号继续清空隔离的数据，迟到回包不能跨越账号或 Room。成员变化仍刷新摘要和名单。设备绑定不受本次布局调整影响。

验收需覆盖真实 widget 注册与绘制、两个标签的内容分离、搜索/媒体入口、成员资料入口、通知模式映射、Agent 选择器只在 Members 显示、标题栏无重复邀请、开关展开/关闭、宽窄窗口保留输入框，以及既有账号/Room epoch 隔离测试。专项测试已通过：真实 widget 注册及 280×775 绘制确认摘要固定、Agent picker 在成员区、名单保留可滚动空间；行映射覆盖 0/1/多个成员与通知模式，成员资料绑定绘制时快照，避免名单刷新重排后点击错误用户。两个标签切换保留原邀请键；迟到成员与 Agent 回包继续核对 Room、账号、服务器及 epoch。标题栏宽窄布局/输入框/开关三项测试通过。最后成功刷新清除错误状态的补丁已交由整库测试与最终构建验证。

最终整库回归：341 项通过，1 项既有忽略；最后补丁纳入构建，Desktop debug build 成功。macOS 宗卷确认后，新版实机已检查：Members 显示真实 3 名成员，Overview 独立呈现 Room 详情/通知/Agent Access；标题栏只有侧栏图标，点击关闭恢复聊天宽度，再点击正常展开；搜索和附件图标分别打开真实历史和媒体页；Agent picker 在 Members 展开，摘要固定、成员仍可滚动，40px 选择器与输入风格一致。
