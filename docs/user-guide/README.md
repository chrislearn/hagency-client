# Hagency desktop guide

Hagency is a native desktop application for Windows, macOS and Linux. Download
the application from [Client Releases](https://github.com/hagency-org/hagency-client/releases/latest)
and follow the [desktop quick start](../../crates/hagency-app/docs/hagency-quickstart.md).

Sign in with your Matrix/Pasion account, select or create a Project, and manage
Agents, providers, budgets and execution approvals in the application.
See [server login](../server-login.md) for the OAuth and server identity boundary.

The former CLI, Web console, static pages and service installer are retired.
No separate browser console or local service installation is required. The OAuth
login callback remains available. The old Fleet/operator manual is available in
Git history and does not describe the current product.

For development, use the [workspace guide](../workspace.md) and
[local development instructions](../local-development.md).
