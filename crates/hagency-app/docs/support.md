## Report a problem / 反馈问题

The Client repository currently has Issues disabled. Use the existing
[Hagency Desktop issue tracker](https://github.com/hagency-org/hagency-desktop/issues)
for application reports, including the current Client version. Current source
development remains in `hagency-org/hagency-client`.

Client 仓库目前未开启 Issues。应用问题可提交到仍开放的
[Hagency Desktop 问题区](https://github.com/hagency-org/hagency-desktop/issues)，
并注明当前 Client 版本。现行源码开发仍位于 `hagency-org/hagency-client`。

Include the app version and commit from **Settings → About**, your operating
system, reproduction steps and the observed result. For a Room-specific problem,
use **Copy Room Diagnostics** from that Room's context menu. Review all logs and
screenshots before publishing them; remove tokens, credentials, private messages
and personal file paths. GitHub sign-in is required to submit an issue.

请提供“设置 → 关于”中的应用版本和提交号、操作系统、复现步骤及实际结果。
房间问题可使用该房间菜单中的“复制房间诊断”。发布日志和截图前请检查并移除令牌、
凭据、私聊内容和个人文件路径。提交 GitHub Issue 需要登录 GitHub。
